SRC=return '😀', #'😀', string.byte('😀',1), string.byte('😀',2)
0=true
1=STRING U+003D U+0000
2=2.0
3=61.0
4=0.0

Cause from javap LexState: source is read through Reader.read() into int current (UTF-16 code units), then read_string saves each current via save(int). save stores only byte low 8 bits in byte[] buff. Final newstring(byte[],...) decodes the bytes as UTF-8. Therefore non-ASCII Java/Lua source literals are irreversibly corrupted: U+4E2D low byte 0x2D => '-', U+D83D low byte 0x3D => '=', U+DE00 low byte 0 => NUL. ASCII source works.
