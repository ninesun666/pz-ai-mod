# 发布说明

## 功能

AI 队友是单人模式实体 NPC 队友模组。玩家主动招募后，队友真实加入 Knox NPC 队伍，可跟随、等待并正常参与战斗。通过独立桥接程序可用模型进行中文对话；模型只允许返回 `none`、`follow`、`wait`，不会取得作弊权限。

## 安全范围

本模组不治疗、不无敌、不强制杀怪、不传送、不修改玩家属性、不生成物品。招募会写入所选世界和玩家模组数据；首次使用请创建可丢弃测试世界并备份重要存档。

## 依赖

- ZombieBuddy 2.3.4，Workshop 3619862853。
- Knox Event Expanded NPC 0.4.0-13，Workshop 3397396843。
- Project Zomboid Windows 42.21.0 实测；仅支持单人、玩家索引 0。

依赖必须从其官方来源单独安装。本模组不包含第三方 JAR、DLL、源码或安装器。

## 安装

解压 `Contents/mods/DC_AI_Teammate` 到所选 Project Zomboid 用户配置目录的 `mods` 下；启用两个依赖和 `DC_AITeammate`。模型功能需要 Python 3.10+ 和 OpenAI 兼容接口；复制示例 JSON 到私有目录后填写配置，绝不分发密钥。完整步骤见安装说明；桥接程序须从另行分发的独立预览包获取，本工坊目录不包含桥接程序。

## 发布状态

这是私密 staging 草稿，尚未上传 Steam 创意工坊。公开发布前仍需确认作者、许可证、封面、桥接下载地址和干净环境验收。
