# 大肥鱼 · 产品体验设计 v1 — 供评审

> 回答四个问题：**她在哪、长什么样、怎么跟她互动、她能做什么。**
> 本文是产品设计（玩家视角）；技术架构见 [DESIGN.md](<ai-mod/docs/DESIGN.md>)。
> 标注约定：〔已实现〕代码已存在并通过测试；〔待实机〕代码已写但未在游戏里验证；〔规划〕尚未实现，本文提出方案待你拍板。

---

## 1. 她在哪里（出现方式与站位）

**出现〔规划〕**：玩家第一次进入新存档，大肥鱼在玩家出生点旁边约 2~3 格的位置站着 —— 不需要"打开菜单招募"，进档就能看到她。这个位置规则与现在世界探针的挂载点一致（玩家旁 1 格，〔待实机〕，正式版建议 2~3 格避免贴脸）。

**站位习惯〔规划〕**：
- **跟随模式**：跟在玩家左后方约 3~4 格，像真实队友一样保持跟行距离；玩家停下来她也会停在附近，不会挤到你脸上。
- **停留模式**：站在你指定她停留的位置不动；你走远她也不跟，但头顶会出现轻微待机动作（见下文动作）。
- **危险反应**：僵尸进入她附近威胁圈时，她会先于你"警觉"——停下当前动作、面向威胁方向，并把她的状态反馈给你（见交互）。

**她占据真实空间**：她是一个真实的游戏角色实体（不是贴在屏幕上的桌宠、不是头顶贴图），会被墙挡住、要绕路、能被你看到被门挡在后面。这是本项目的核心产品承诺：她活在游戏世界里，而不是浮在游戏上面。

## 2. 她长什么样

**当前〔已实现的占位〕**：游戏内通用幸存者模型，女性角色，名字"大肥鱼"。这是明确的 placeholder，仅用于验证渲染管线。

**最终形象〔规划，需你拍板〕**——设计方向建议："鲸鱼娘"：深蓝/白色调的少女形象，标识性元素：

| 元素 | 设计建议 | 实现载体 |
|---|---|---|
| 身份标识 | 蓝白配色服装 + 头部鲸鱼耳/鳍造型帽饰 | 自定义服装物品（贴图方案）或自定义模型 |
| 命名 | 头顶显示"大肥鱼" | 游戏角色名机制 |
| 辨识度 | 远处一眼能与普通幸存者区分的剪影（帽鳍剪影） | 同上 |

**两条实现路线（第 7 节开放问题，请你选）**：
- **A 贴图方案**（便宜）：用游戏内服装/贴图系统拼出蓝白配色 + 鳍形帽饰。工作量小、风险低，但造型受限，"像穿了鲸鱼主题服装的幸存者"。
- **B 自定义模型**（贵）：完整自定义 3D 模型 + 动画绑定。还原度高（真正像一只拟人鲸鱼娘），但需要建模、动画烘焙和引擎适配，工作量大一个数量级。

建议先 A 后 B：先用 A 打通全部玩法验收，模型作为后续升级。

## 3. 怎么跟她互动（无文字输入）

核心原则：**不打字、不弹窗、不抢鼠标**。所有交互走游戏原生交互形态。

### 3.1 指令：右键菜单〔已实现交互壳，待接线〕
在世界里点右键，菜单中出现三项中文指令：

```
大肥鱼：跟随        ← 她会跟上你，绕过障碍
大肥鱼：停留        ← 她原地待命，不再跟走
大肥鱼：重新集合    ← 你走远后叫她归队
```

当前状态：菜单已能出现（〔已实现〕），但因实体执行器未接线，三项显示"实体尚未就绪"并禁用〔已实现的诚实状态〕。接线后变为可用。

### 3.2 即时反馈〔规划〕
每次指令后她有**短促可感**的反馈，不用长文本打断游戏：
- 语音/音效级别的短反馈（如一声轻快的应答音）+ 头顶 1 秒小图标（跟随=脚印、停留=立正、集合=旗子）。
- 相同反馈有冷却，不刷屏。

### 3.3 她主动跟你说的事〔规划〕
她只在**事件时刻**开口（本地台词，非网络模型调用；可选接入大模型做性格化台词，但模型调用永不阻塞游戏）：
- 掉队：跟丢你时说"等等我——"（冷却，不重复刷）。
- 危险：发现僵尸接近时短促提醒。
- 重逢：重新汇合时一句轻松的话。
- 你停留指令下她被僵尸围住：提醒 + 自动撤退行为（见下）。

台词形态：屏幕侧边短暂气泡/游戏字幕机制，不是聊天框，不要求你回复。

## 4. 她能做什么（能力清单）

### 4.1 核心行为（第一优先级交付）
| 能力 | 说明 | 状态 |
|---|---|---|
| 跟随 | 保持 3~4 格跟行距离，绕过短障碍追上你；卡住会自行恢复 | 仲裁逻辑〔已实现〕，实体移动〔规划〕 |
| 停留 | 原地不动；你不叫她她不跟走 | 仲裁逻辑〔已实现〕，实体移动〔规划〕 |
| 重新集合 | 距离过远时按指令归队；超远距离自动触发 | 仲裁逻辑〔已实现〕 |
| 撤退 | 威胁过大时先拉开距离再回位 | 仲裁逻辑〔已实现〕 |
| 卡住恢复 | 跟丢/卡墙后自动重寻路，不再无脑撞墙 | 节流/取消逻辑〔已实现〕，移动〔规划〕 |

### 4.2 存在感细节（第二优先级）
- **待机动作**〔规划〕：站立时有轻微的待机动画（重心晃动、偶尔环顾），不是僵直站桩。
- **面向逻辑**〔规划〕：停留时面向你离开的方向；警觉时面向威胁。
- **作息**〔规划·远期〕：安全区内坐下休息等低成本生活动作。

### 4.3 明确不做什么（范围红线）
- **不做**自动战斗杀丧尸（战斗 AI 是巨大工程，且容易抢玩家的高光时刻；第一版她回避战斗而非参与战斗）。
- **不做**拾取/搬运/建造等生存劳动（那会把产品变成打工 NPC；若你想要"工作"能力，见 4.4 供拍板）。
- **不做**网络/大模型逐帧决策——模型只负责可选的台词性格，行为永远本地确定性。

### 4.4 "工作"能力扩展（〔规划〕，需要你拍板要不要）
如果你想让她"干活"，建议按这个顺序逐档解锁（每档都是独立可验收的小闭环）：
1. **哨兵**：停留模式下监视半径内僵尸并向你报警（复用危险感知，纯提醒不战斗）——性价比最高。
2. **背包辅助**：负重超限时走到你身边，示意她可以帮你背（简化为移动储物，不实现复杂物品 AI）。
3. **向导**：记住你去过的区域，停留时可在菜单里"问她路"——地图标记，非导航寻路。
4. 更复杂的（做饭、守卫射击等）建议不做：工程量失控且会变成另一个游戏。

## 5. 一次典型游玩体验（目标场景 walkthrough）

> 你出生在玫瑰木镇安全屋。进档，屋里已经站着一位蓝白色调的少女，头顶名字"大肥鱼"。她朝你挥了下手（登场反馈，仅首次）。
>
> 你出门搜刮，她自动跟在左后方两三格。你翻窗进了一间药房，她没跟上来——窗户绕路远。两秒后她出现在门口："找到一条路啦。"（掉队自动恢复，不需要你操作。）
>
> 转角遇到 3 只丧尸。她先停下脚步面向它们，屏幕边缘传来她短促的一声"……它们来了。"你决定不打，走为上。她在威胁解除后自己绕回你身后。
>
> 你进一栋楼想单独探索，右键 →"大肥鱼：停留"。她应了一声，站在门口朝你离开的方向望。你在楼上搜完下楼，她还在原地，环顾着街道。
>
> 丧尸游荡着靠近她，她在你回来前自动退到安全侧，你下楼看到她离原地两格、背靠墙面向街道——你右键 →"大肥鱼：跟随"，她小跑两步回到你身后："来啦！"
>
> 存档退出。明天再进，还是她——同一个名字、同一身打扮、还记得上次的跟随指令。世界还是那个世界，但队伍里多了一个活人。

## 6. 交互总览（一图）

```
玩家操作              大肥鱼反应                 游戏世界影响
────────────────────────────────────────────────────
右键→跟随         →  应答音+头顶图标，跟行3~4格     真实寻路，会被挡/绕路
右键→停留         →  应答音，原地待机面向你          不再跟随
右键→重新集合     →  应答音，主动寻路归队            穿越障碍追上
(自动)掉队        →  "等等我——"(冷却)              自动重寻路
(自动)危险        →  短促提醒+面向威胁              停止跟行/自动拉开距离
存档→重载         →  同一身份恢复，无重复            ModData 绑定
```

## 7. 请你拍板的决策点

1. **形象路线**：A 贴图拼装（先上）还是 B 自定义模型（一步到位，慢）？→ 建议 A→B。
2. **指令形态**：右键菜单是否足够？要不要附加快捷键（如 V 键轮询模式）？
3. **能力边界**：4.3 的红线（不战斗、不做工）你是否同意？4.4 里最想要哪一档"工作"（哨兵/背包/向导）？
4. **出现方式**：新档自动出现在出生点旁，符合"进档就能看到"的预期吗？
5. **台词密度**：反馈偏好"安静可靠"（只在关键事件说话）还是"活泼话痨"（更高频小动作台词）？
